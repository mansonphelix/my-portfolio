Linux Server Setup & Hardening

Linux · 11 min read

What you'll learn

  • Minimal OS installation and LVM configuration
  • SSH hardening and key-based authentication
  • Firewall setup with UFW
  • Ongoing maintenance and backup strategies

Linux servers are the backbone of most modern infrastructure. This guide covers the essential steps I follow when provisioning a new Linux server for small offices, including baseline configuration, user management, firewall setup and basic hardening.

1. Initial OS installation

  • Use a minimal installation where possible to reduce attack surface
  • Configure LVM during install for flexible disk management
  • Set a static IP address and hostname that fits your naming scheme
  • Enable automatic security updates during installation if available

2. System updates and essentials

sudo apt update && sudo apt upgrade -y
sudo apt install -y ufw fail2ban curl git htop

Keep the system fully patched before installing additional services. Install only the packages you actually need.

3. User and SSH configuration

  • Create a dedicated admin user with sudo privileges
  • Disable root SSH login in /etc/ssh/sshd_config
  • Use SSH key authentication instead of passwords
  • Change the default SSH port to reduce automated attacks

4. Firewall setup

Enable the firewall early and allow only required ports. A typical server might need SSH and one or two application ports open.

5. Ongoing maintenance

  • Monitor disk usage and log rotation
  • Review fail2ban logs periodically
  • Apply security updates weekly
  • Keep off-site backups of critical configuration files
