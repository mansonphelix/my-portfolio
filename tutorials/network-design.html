Designing a Small Office Network (CCNA Basics)

Networking · 12 min read

What you'll learn

  • How to gather requirements for a small office network
  • IP addressing planning with VLAN separation
  • Core device selection and switch configuration
  • Testing and handover best practices

A reliable small-office network starts with clear requirements, sensible IP planning, and equipment that matches the scale of the organisation. This guide walks through the practical steps I use when designing LANs for offices and municipal units in Ghana.

1. Gather requirements

  • Number of users and devices (PCs, printers, phones, CCTV, access points)
  • Need for guest Wi-Fi separation
  • Internet bandwidth and whether failover is required
  • Physical layout — floors, cable runs, power points

2. IP addressing plan

Use private RFC 1918 ranges. A common simple scheme:

LAN clients:     192.168.10.0/24
Servers / NVR:   192.168.20.0/24
Management:      192.168.30.0/24
Guest Wi-Fi:     192.168.40.0/24

Document every static assignment. Reserve low addresses for gateways and infrastructure.

3. Core devices

  • Router / firewall — internet edge, NAT, basic firewall rules
  • Managed switch — VLANs if you need separation (recommended even in small sites)
  • Access points — controller-less is fine for small sites; place them for coverage, not convenience

4. Cabling and topology

Prefer structured cabling to a central rack. Keep runs under 90 m for copper. Label both ends. A star topology with a clean patch panel saves hours later.

5. Basic security checklist

  • Change default credentials on every device
  • Separate guest network from internal LAN
  • Disable unused switch ports or put them in a black-hole VLAN
  • Document admin access and backup configs
Good documentation is part of the design. Future you (or the next engineer) will thank you.

6. Test before handover

Verify DHCP, DNS, internet, inter-VLAN routing if used, and printer discovery. Walk the floor with a laptop and phone to confirm Wi-Fi coverage.

This foundation scales cleanly when the organisation grows — add another switch, extend VLANs, or introduce a proper firewall without redesigning everything.
